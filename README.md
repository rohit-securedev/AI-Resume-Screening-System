# AI Resume Screening System

An AI-powered web application that automates resume screening and candidate ranking using Natural Language Processing (NLP) and Machine Learning.

## Features

* Recruiter Authentication
* Resume Upload (PDF/DOCX)
* Job Description Management
* Resume Parsing
* AI-based Candidate Ranking
* Dashboard Analytics
* Candidate Search & Filters
* PDF/CSV Report Generation
* Admin Panel
